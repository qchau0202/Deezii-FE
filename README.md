# Deezii
Deezii is an AI Design Assistant platform built for Vietnamese users, helping them create posters, banners, and marketing materials simply by entering Vietnamese text. The product operates on a SaaS (Software-as-a-Service) model, accessible directly via web browsers or a forthcoming mobile app.
